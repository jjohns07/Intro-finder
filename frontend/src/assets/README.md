# Authentication photography

`auth-entrance.jpg` is the bundled architectural photograph used by both auth
views. It is served locally by Vite, without a runtime image-host dependency.

- Source: [Unsplash image](https://images.unsplash.com/photo-1600585154340-be6161a56a0c)
- License: [Unsplash License](https://unsplash.com/license)
- Download: 1600px width, JPEG quality 85.
- Treatment: responsive crop, muted saturation, and a dark gradient in
  `src/styles/auth.css`. All branding and text remain accessible HTML.

The pre-existing `auth-architecture.jpg` is retained but is no longer imported.
